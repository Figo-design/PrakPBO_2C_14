# SewaGear: Aplikasi Penyewaan Perlengkapan Pendakian

Proyek awal untuk Quiz Praktikum Live Coding PBO (materi Pertemuan 9, 10, 11).

## Membuka di NetBeans
File → Open Project → pilih folder `SewaGear` (proyek Maven), lalu jalankan `Main.java` (Shift + F6).

## Tanpa NetBeans (JDK 17+)
```
javac -d out src/main/java/id/ac/polinema/sewagear/*.java
java -cp out id.ac.polinema.sewagear.Main
```

## Catatan
Setiap soal kuis dikerjakan dari kode awal ini, bukan dari hasil soal lain.
